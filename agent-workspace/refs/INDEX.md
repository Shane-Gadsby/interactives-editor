# Ixia reference: where everything is

Every file here is generated from the editor itself on each build. Read only the one you need. Paths are relative to refs/.

## Layers
- layers/bones.md (3 lines): Bones
- layers/charts-progress-connectors.md (7 lines): Progress bars, charts and connectors
- layers/common.md (3 lines): Fields every layer has (position, accessibility, bindings, drag and drop)
- layers/components.md (3 lines): Components (instance layers)
- layers/defaults.md (24 lines): Defaults per layer type (what add_layer fills in)
- layers/draw-script.md (31 lines): Script layers (type "draw") and the g drawing API
- layers/images.md (3 lines): Pictures (image layers)
- layers/layout-frames.md (3 lines): Auto layout frames and their limits
- layers/overlays-dialogs-accordions.md (3 lines): Accordions, tabs, overlays (tooltips, modals, confirms, prompts) and dialogs
- layers/paths.md (3 lines): Paths and paints
- layers/repeaters-keynav.md (3 lines): Repeaters, repeat.select and keyboard navigation (keyNav)
- layers/shader.md (5 lines): Shader layers and shader filters
- layers/states.md (3 lines): Layer states (hover, pressed, focus, disabled, expression)
- layers/text.md (5 lines): Text layers (rich text runs, per letter animation)
- layers/web-controls.md (3 lines): Buttons and inputs
